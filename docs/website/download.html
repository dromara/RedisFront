Install Notes

安装说明Installation notes

Windows

首次运行如遇 SmartScreen 提示，选择「仍要运行」即可；便携版解压后执行 RedisFront.exe。If SmartScreen warns on first run, choose "Run anyway". For the portable build, unzip and run RedisFront.exe.

macOS

Apple Silicon 选择 arm64 包。首次打开如被 Gatekeeper 拦截，请在「系统设置 → 隐私与安全性」中放行。Pick the arm64 build on Apple Silicon. If Gatekeeper blocks the first launch, allow it under System Settings → Privacy & Security.

Linux

sudo dpkg -i RedisFront.deb
sudo rpm -i RedisFront.rpm

或直接解压 tar.gz 后运行启动脚本。Or extract the tarball and run the launcher script.

数据与连接配置保存在用户目录 ~/.redisfront 下，升级不会丢失。 Data and connection settings live in ~/.redisfront and survive upgrades.
