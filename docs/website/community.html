Dromara 产品矩阵Dromara product matrix

RedisFront 是 Dromara 开源社区的成员项目。社区里还有更多经过生产验证的 Java 开源产品，覆盖认证、运维、数据与中间件。RedisFront is a member project of the Dromara community, which also maintains many production-proven Java products across auth, ops, data and middleware.

Sa-Token

一站式 Java 权限认证框架，覆盖登录认证、权限校验、SSO 与 OAuth2.0。An all-in-one Java auth framework covering login, permissions, SSO and OAuth2.0.

Hutool

小而全的 Java 工具类库，让 Java 语言也可以“甜甜的”。A small yet complete Java utility library.

RuoYi-Vue-Plus

重写 RuoYi-Vue 全部功能的后台管理系统，集成 Sa-Token 与 Mybatis-Plus。A full rewrite of RuoYi-Vue, integrating Sa-Token and Mybatis-Plus.

MaxKey

业界领先的 IAM 单点登录认证系统，支持 OAuth2.x、OIDC、SAML2.0 与 CAS。A leading IAM single sign-on system supporting OAuth2.x, OIDC, SAML2.0 and CAS.

TLog

轻量级分布式日志追踪，10 分钟接入即可完成微服务链路追踪。Lightweight distributed log tracing — integrate in 10 minutes.

dante-cloud

支持阻塞式与响应式并行的微服务云原生基座，基于领域驱动模型设计。A microservices cloud-native platform supporting both blocking and reactive styles, built on DDD.

mica-mqtt

基于 Java AIO 实现的高性能 MQTT 客户端与 Broker，百万级连接。A high-performance Java AIO MQTT client and broker for millions of connections.

mayfly-go

Web 版统一运维平台，纳管 Linux、Docker 与关系型数据库。A web-based unified ops platform managing Linux, Docker and relational databases.

dbswitch

完全开源的异构数据库迁移同步工具。A fully open-source heterogeneous database migration and sync tool.
