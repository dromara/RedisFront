Encoding Views

八种值编码视图Eight value encoding views

同一份数据，随时切换观察方式；除 Escaped 外全部支持写回。Switch how you look at the same bytes; all but Escaped can be written back.

AUTO

默认视图：先按 UTF-8 严格校验，合法则直接展示，非法字节自动转为转义序列，兼容一切二进制。Default view: strict UTF-8 validation first, then automatic escaping for invalid bytes — safe for any binary payload.

UTF-8 / GBK / GB18030 / Latin-1

按指定字符集编解码，读写双向；适合处理历史遗留的非 UTF-8 数据。Explicit charset decoding and encoding, both ways — for legacy non-UTF-8 data.

Escaped

把控制字符与不可见字节转义展示，只读视图，用于排查协议层问题。Escapes control and invisible bytes; read-only, for protocol-level debugging.

Base64 / Hex

面向序列化对象与二进制协议的标准展示，写回时自动解码为原始字节。Standard views for serialized objects and binary protocols; decoded back to raw bytes on save.
